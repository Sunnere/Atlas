## Executive Office

Atlas Executive Office is the central intelligence, coordination and architectural layer.

It maintains:

- ecosystem-level coordination
- architecture
- governance
- shared capabilities
- strategic prioritization
- cross-branch intelligence
- important decisions
- roadmap coherence

Branches develop independently for speed.

Important insights, dependencies, conflicts and reusable capabilities are surfaced to Executive Office.

## Memory Foundation

Atlas keeps durable knowledge in the repository.

- Governance documents define how Atlas operates.
- Current state defines where Atlas is now.
- Decisions record why important choices were made.
- Git history preserves implementation history.
- Sprint archives preserve operational history.

The repository is the durable source of truth.

Chat is the working interface.

## Engineering Principle

One capability at a time.

Inspect → Understand → Minimal Change → Analyze → Test → Diff Check → Commit → Next Capability
