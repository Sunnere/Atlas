# Market Intelligence

Denne mappen inneholder analyser som danner grunnlaget for investeringsbeslutninger.

Prinsipper:

- Ingen påstander uten dokumenterte kilder.
- Rådata lagres i /data.
- Analyser lagres i /market.
- Alle analyser skal kunne oppdateres uten å endre strukturen.

Analyseområder:

- Tourism
- Land
- Construction
- Regulations
- Competitors
- Demographics
- Investment
