# Tourism Analysis

Formål:

Dokumentere etterspørselen etter overnatting i Thailand.

Datakilder vil blant annet inkludere:

- Turistankomster
- Sesongvariasjoner
- Gjennomsnittlig oppholdstid
- Viktigste nasjonaliteter
- Hotellbelegg
- Korttidsutleie

Konklusjoner skal alltid baseres på dokumenterte kilder.
