# Atlas Matrix

## Purpose

Atlas Matrix is the operating model for the ecosystem.

The model allows multiple branches to develop independently while maintaining centralized coordination, architectural coherence and shared learning through Atlas Executive Office.

## Operating Branches

### Growth OS

Owns Bonusvarsel, growth, product, monetization and operational development.

### Minihus Thailand

Owns the Minihus project, market, concepts, economics and execution.

### Atlas Invest

Owns Atlas' first financial product and proof-of-capability.

### Ecosystem Strategy

Owns cross-ecosystem strategy, synergies, prioritization and long-term structure.

## Matrix Principle

Branches develop independently for speed.

Important decisions, insights, dependencies, conflicts and reusable capabilities are surfaced to Atlas Executive Office.

Atlas Executive Office evaluates whether a capability should remain local or become a shared Atlas capability / Core capability.

## Shared Capability Rule

A branch may identify and prototype a capability locally.

If that capability can serve multiple branches, it is raised to Executive Office for evaluation.

Flow:

Branch
→ Discovery
→ Executive Office
→ Local Capability OR Shared Capability / Atlas Core

## Communication Model

Branches do not need to be tightly coupled to each other.

The Matrix provides coordination across domains.

Atlas Executive Office acts as the central integration layer.

## North Star

Separation gives speed.

Coordination gives control.

Atlas Matrix provides the whole-system view.

🧭 Always north.
